# Real Time Location Tracker
Simple Back-end project by using map with react.js and socket.io

# Run the Project
npm install
npm start

Open http://localhost:8000 . A private room is created automatically and the URL becomes /?room=abc123. Share that link (or use "Copy link") so others join the same room.
